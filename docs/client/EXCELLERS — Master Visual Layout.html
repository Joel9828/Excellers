02 · Canvas & colour

Shades of white, with three brand notes

Every surface is a white: pure white, then Light Steel’s two palest tones. The darker steels are used only for lines, icons and text. Brand colour appears only on headings, primary actions, hover lines and one dot. There is no dark field.

07 · Accessibility

WCAG AA, built in

Structure

  • Landmarks: header, nav, main, footer
  • One h1; one h2 per section; h3 per card or question
  • Skip link first in the tab order
  • Decorative mesh, ticker and icons are aria-hidden

Interaction

  • Targets at least 44px
  • Focus ring 2px Honolulu, 3px offset, never removed
  • Stepper uses tab roles and arrow keys
  • Errors use text and an icon, announced with role="alert"

Motion & colour

  • Hover motion 200–350ms, 4px at most
  • Reduced motion removes all transitions and the traveling line
  • Colour is never the only signal
  • Every text and UI pair passes the ratios above
